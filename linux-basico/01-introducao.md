# 01 — Introdução ao Linux

O que é Linux?
- Linux é um kernel (núcleo) criado por Linus Torvalds. "Linux" é frequentemente usado para referir-se a sistemas operacionais completos baseados nesse kernel (distribuições).

Distribuições populares
- Ubuntu, Debian, Fedora, CentOS/Rocky, Arch Linux, openSUSE.

Componentes principais
- Kernel: gerencia hardware e recursos.
- Shell: interface de linha de comando (bash, zsh, fish).
- Utilitários: ferramentas GNU e outras que formam o sistema.

Conceitos essenciais
- Usuário e permissões
- Sistema de arquivos (/, /home, /etc, /var, /usr)
- Processos e serviços

Dicas iniciais
- Use uma máquina virtual (VirtualBox, QEMU) ou WSL para praticar.
- Evite comandos destrutivos sem entender (`rm -rf /` "> nunca execute isso").

Exercício rápido
- Abra um terminal e rode:

  pwd
  ls -la ~
  whoami
