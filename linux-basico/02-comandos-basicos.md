# 02 — Comandos Básicos

Navegação e listagem
- `pwd` — mostra o diretório atual
- `ls` — lista arquivos
- `cd` — muda de diretório

Manipulação de arquivos
- `cp` — copiar arquivos
- `mv` — mover/renomear
- `rm` — remover (cuidado)
- `mkdir` — criar diretórios
- `touch` — criar arquivo vazio

Visualização de arquivos
- `cat`, `less`, `head`, `tail`

Busca e texto
- `grep` — procura texto
- `find` — encontra arquivos por critérios

Ajuda
- `man <comando>` — manual
- `<comando> --help` — ajuda rápida

Redirecionamento e pipes
- `>` e `>>` — redirecionam saída para arquivo
- `|` — encadeia comandos

Exercício
- Crie um diretório `teste-linux`, dentro crie um arquivo `ola.txt` com `echo "Olá" > ola.txt`, liste e mostre o conteúdo.
