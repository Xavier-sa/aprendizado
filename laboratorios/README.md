# Scripts

Experimentos pequenos, utilitarios e provas de conceito ficam aqui. Eles mostram pratica incremental sem poluir a raiz do repositorio.

| Pasta | Conteudo |
| --- | --- |
| `laboratorio-python/` | Scripts Python de estudo, terminal, validacao e automacao. |
| `laboratorio-cpp/` | Exercicios e arquivos C++ avulsos. |

## Padrao de Nome

- Python: `nome_descritivo.py`.
- C++: `nome-descritivo.cpp` ou `nome_descritivo.cpp`, mantendo consistencia dentro da pasta.
- Evite nomes soltos como `teste.py`, `novo.py` ou `main.py` quando o arquivo nao for o ponto de entrada real.
