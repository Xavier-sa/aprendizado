# 01-php-legacy

Versão inicial em PHP com funcionalidades básicas de controle de fiado.

## O que contém
- `index.php` — sistema de cadastro de clientes e marcas de pagamento
- `schema.sql` — estrutura do banco de dados com tabelas `clientes` e `compras`

## Características
- CRUD básico de clientes e compras
- Marcar compras como pagas ou pendentes
- Totalização por cliente

## Observações
Esta versão demonstra a primeira tentativa de traduzir regras de negócio em PHP. O código serve como base histórica para comparar com a versão web atual.
