# Contribuindo

Este repositorio documenta uma evolucao real de aprendizado. Contribuicoes devem melhorar clareza, acessibilidade, organizacao ou confiabilidade sem apagar o contexto historico.

## Como Contribuir

1. Abra uma issue ou descreva claramente o problema antes de grandes mudancas.
2. Prefira alteracoes pequenas e bem explicadas.
3. Mantenha exemplos antigos quando eles ajudarem a mostrar evolucao.
4. Use nomes descritivos para arquivos e pastas.
5. Atualize o README do projeto afetado quando mudar forma de executar ou entender o codigo.

## Padroes de Nome

- Documentos: `nome-do-documento.md`.
- Scripts Python: `nome_descritivo.py`.
- Pastas: nomes curtos, legiveis e sem acentos quando possivel.
- Evite nomes genericos como `teste`, `novo`, `main` quando o arquivo nao for ponto de entrada real.

## Acessibilidade

Toda contribuicao visual deve considerar contraste, navegacao por teclado e leitores de tela. Nao use apenas cor para comunicar estado.

## Commits

Use mensagens objetivas, por exemplo:

```text
docs: melhora guia de organizacao
refactor: move arquivos soltos para laboratorios
fix: corrige caminho de importacao do logo
```
