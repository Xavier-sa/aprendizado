# PsicoABA

Sistema simples de agendamento e administração para psicóloga especializada em ABA.

## Recursos
- Login administrativo para psicóloga
- Cadastro de pacientes com informações essenciais e LGPD
- Agendamento em blocos de 50 minutos
- Checkbox para repetir consultas em terças-feiras
- Painel administrativo com evolução de pacientes e finanças
- Gráficos de idade e consultas
- Seção editável sobre ABA no painel admin
- Agentes especializados de psicologia e finanças

## Tecnologias
- PHP
- HTML
- CSS
- JavaScript
- SQLite

## Instalação
1. Copie `.env.example` para `.env`.
2. Ajuste as variáveis se necessário.
3. Garanta que o PHP tenha permissão de escrita na pasta `data/`.
4. Execute via servidor local PHP: `php -S localhost:8000`.
5. Acesse `http://localhost:8000`.
