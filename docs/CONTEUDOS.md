# Catálogo educacional

As sete trilhas planejadas são: Fundamentos absolutos; Ferramentas; Linguagens; POO e arquitetura; Desenvolvimento web moderno; Banco de dados; DevOps, segurança e qualidade.

## Contrato de uma aula

Toda aula nova deve conter: título e nível; objetivo; pré-requisitos; explicação simples; definição técnica; motivação e uso; exemplo comentado; erros comuns; boas práticas; exercício guiado; desafio independente; cinco questões com correção comentada; e próximo conteúdo recomendado.

## Conteúdo disponível

- Aula 01 — O que é programação? Inclui algoritmo de média, cinco fundamentos da programação, mapa de conceitos sofisticados com pré-requisitos, erros comuns, exercício de decisão, desafio de desconto e quiz.
- Glossário — 50 termos que percorrem fundamentos, web, arquitetura, qualidade e segurança.
- Glossário visual — os 50 termos possuem diagrama, explicação simples e exemplo prático; API, JSON, JWT e CORS usam ilustrações detalhadas.
- Laboratório JavaScript — conteúdo legado de sintaxe, funções, arrays, objetos, DOM e playground.
- Laboratório SQL — conteúdo legado de conceitos, DDL, DML, SELECT e quiz.
- GitHub Foundations — simulado legado por domínios.

## Regra editorial

Usar frases curtas, exemplos progressivos e linguagem simples sem perder precisão técnica. Conceitos avançados devem declarar pré-requisitos. Kubernetes nunca é requisito para iniciar fundamentos.
