// erros e lições

Erros que quase me fizeram desistir

Esses momentos dolorosos foram os que mais me ensinaram.

🔐

Segurança é essencial

Criei um sistema sem controle de acesso adequado. Qualquer usuário podia acessar qualquer página. Aprendi que autenticação e autorização são a base — não um extra.

Fase Backend
🗄️

Estrutura de banco de dados

Meu primeiro banco tinha tudo em uma tabela só. Refatorar aquilo foi um pesadelo. Aprendi sobre normalização, relacionamentos e a importância de planejar antes de codar.

Fase Banco de Dados
🔀

Organização de código

PHP misturado com HTML misturado com SQL em um único arquivo. Funcionava, mas era impossível de manter. Aprendi MVC, separação de responsabilidades e código limpo.

Fase Arquitetura
🐛

Depuração é uma habilidade

Passei horas num bug que era uma vírgula faltando. Aprendi a usar ferramentas de debug, ler erros com atenção e ter paciência. A solução sempre está lá.

Fase Debug
💭
