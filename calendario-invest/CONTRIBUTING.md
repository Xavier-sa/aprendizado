# Como contribuir

1. Abra uma issue com o comportamento esperado e dados fictícios.
2. Faça a alteração em uma branch própria e execute o CI do projeto.
3. Abra um PR com o resumo, os testes e qualquer mudança sobre os dados coletados.

Envie relatos de segurança e privacidade em particular para
xavier@wasxtech.com.br. Não inclua senhas, dados pessoais ou credenciais em issues,
capturas e PRs.
